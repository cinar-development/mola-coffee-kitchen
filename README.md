About

MOLA Coffee & Kitchen is a fictional café website concept designed as a modern, mobile-first digital experience for a contemporary coffee shop.

The project focuses on:

* Clear brand presentation
* Mobile-first user experience
* Menu discoverability
* Direct contact and WhatsApp conversion
* Responsive editorial layouts
* Accessibility
* Performance
* Technical SEO foundations

Features

* Responsive design
* Mobile navigation
* Category-based menu filtering
* Editorial gallery layout
* WhatsApp and telephone contact links
* Semantic HTML5 structure
* Accessibility-focused navigation
* Keyboard-friendly interactions
* prefers-reduced-motion support
* Open Graph metadata
* Twitter metadata
* Schema.org structured data
* Lazy-loaded images
* Vanilla JavaScript
* No frontend framework dependencies

Technology

* HTML5
* CSS3
* Vanilla JavaScript

Design Direction

The visual direction combines:

* Warm minimalism
* Editorial layout
* Modern coffee culture
* Strong typography
* Natural imagery
* Restrained color usage
* Conversion-focused UX

The design intentionally avoids excessive gradients, glassmorphism, excessive rounded cards, unnecessary animations, and generic SaaS-style UI patterns.

Project Principles

The project is being developed with the following principles:

* Mobile-first
* Performance-conscious
* Accessible by default
* Semantic markup
* Minimal dependencies
* Maintainable code
* Clear conversion paths
* Production-ready foundations
